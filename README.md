# rr_cn_subtitles

にじさんじ 鈴原るる 直播内容的**中文翻译字幕**（非官方）。

## 内容

本仓库收录 **17 份字幕文件**，覆盖 **16 场直播**。格式为 `.ass` 16 份、`.srt` 1 份。

- 文件名即对应直播的标题，已去掉 `-1920x1080-avc1-mp4a` 之类的下载后缀、尾部 `.mp4` 与 `[视频 ID]`
- トモコレ 系列的多个分段已合并为单条完整时间轴
